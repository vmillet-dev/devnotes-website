Télécharger

DevNotes pour votre ordinateur

Télécharger l'installateur Windows

Sur la page de la version, prenez le fichier qui finit par _x64-setup.exe. Il s'installe pour votre compte, sans droits administrateur.

Autres formats
  • Paquet MSI_x64_en-US.msiPour un déploiement par stratégie de groupe.
  • Exécutable portable-windows.exeSans installation, à lancer d'où vous voulez.
Télécharger l'AppImage

Sur la page de la version, prenez le fichier qui finit par _amd64.AppImage. Toutes les distributions, rien à installer.

Autres formats
  • Paquet .deb_amd64.debDebian, Ubuntu et dérivées.
  • Paquet .rpm.x86_64.rpmFedora, RHEL et dérivées.
  • Binaire seul-linuxL'exécutable, sans paquet.

Les mises à jour arrivent ensuite dans l'application, qui les vérifie avant de les installer. Pas de version macOS pour l'instant.
