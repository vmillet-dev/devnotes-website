Documentation

How to use DevNotes day to day: writing and organising your notes, pasting a snippet from anywhere, the tools, the API client and the safety of your data.

Checked on DevNotes 0.12

DevNotes keeps your snippets, notes and lists in an encrypted library on your machine, with some thirty offline tools and an API client. These pages explain how to use it, in the order you discover it. If you are new, start with getting started.

  • Getting startedInstalling DevNotes, choosing your library’s passphrase, and a tour of the sample notes of the first launch.
  • WritingThe three kinds of note, a snippet’s fields to fill, the code editor and Prettier, formatted notes, checklists and attachments.
  • Organising and findingSpaces and their folders, the Board view, tags, search, filters, sorting and multiple selection.
  • Quick paste and shortcutsFinding a snippet and pasting it without leaving what you are doing, capturing the clipboard into a note, and setting the shortcuts.
  • The toolsSome thirty utilities that run on your machine and call nothing: encoding, hashing, converting, generating, reading a date, calculating, and references.
  • The API clientSending HTTP and GraphQL requests, opening WebSockets, filing them in collections, and varying them from one environment to another.
  • Security and backupsWhat is encrypted and how, the passphrase, several libraries, backup copies, the trash, versions and undo.
  • Import and exportExporting everything, a space or a selection into a .devnotes archive, protected or not, importing it again without duplicates, and copying notes as Markdown.
  • SettingsTheme, language and density, the editor, how the window behaves, global variables, shortcuts and security.
  • QuestionsThe price, macOS, syncing, a forgotten passphrase, the Windows warning, and where your data goes.

In the application

The title bar’s About menu opens a Getting started guide, the list of Keyboard shortcuts active wherever you are, and the What’s new of each version. Shortcuts are set in File → Preferences… → Shortcuts.
