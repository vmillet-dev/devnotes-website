Démarrer

DevNotes regroupe quatre zones : Notes, Outils et HTTP dans la barre latérale, plus la recherche globale.

Créez votre premier contenu avec le bouton Nouvelle note ou un raccourci.

Ctrl N        Snippet de code
Ctrl Maj N    Note
Ctrl Maj L    Liste de tâches
Tout est stocké localement. Aucun compte n’est nécessaire.

Bibliothèque

Les contenus sont rangés dans des espaces (Personnel, Travail, Veille…) avec des sous-dossiers. Filtrez par type (snippets, notes, tâches) ou par tag.

Trier et regrouper

Triez par date de modification, date de création, priorité, format ou titre. Regroupez par date, priorité ou format, et gardez les notes épinglées en tête.

Priorités

Clic droit sur une carte, puis Priorité, ou touche 0 à 4 : Aucune, Basse, Moyenne, Haute, Urgente.

Notes et snippets

Une note accepte titres, listes, liens, citations, tableaux et blocs de code. Elle est enregistrée en Markdown.

Un snippet contient un bloc de code, son langage et ses champs {{à remplir}}.

Formater avec Prettier

Le bouton Formater (Maj Alt F) gère JavaScript, TypeScript, JSON, CSS, SCSS, HTML, Markdown, YAML et GraphQL. Largeur de ligne, indentation, guillemets, points-virgules et virgules finales se règlent pour toute la bibliothèque.

SQL, Rust, Go et Shell ne passent pas par Prettier : le bouton y est désactivé et en explique la raison.

Outils

14 utilitaires, tous hors ligne : convertisseur de casse, générateur de slug, analyseur d’URL, hash et HMAC, mots de passe, UUID, encodeurs URL et Base64, conversion JSON, TOML, XML et YAML, couleurs, JSON Diff, générateurs JSON et Lorem ipsum.

Chaque outil propose Enregistrer comme note : le résultat rejoint un espace, avec ses tags.

Dans Hash / HMAC, la clé n’est jamais enregistrée avec la note.

HTTP

Organisez vos requêtes (REST, GraphQL, WebSocket) en collections et dossiers. Chaque requête a ses paramètres, en-têtes, authentification, corps, scripts et tests.

Environnements

L’ordre de résolution est : requête, dossier, collection, environnement, globales. Les variables s’écrivent ainsi :

{{baseUrl}}/customers/{{customerId}}/invoices?page=1&limit=50

Les secrets sont scellés, jamais exportés, et masqués dans la console.

Exécuter une collection

Le runner enchaîne les requêtes, affiche les tests réussis ou échoués et exporte un rapport.

Générer le code

20 langages et runtimes, de cURL à Elixir. Les secrets restent en variable sauf si vous activez Inclure les secrets, ce que l’app demande à chaque fois.

FAQ

Mes données quittent-elles mon ordinateur ?

Non. Aucun outil n’appelle le réseau et les secrets ne sont jamais exportés.

Puis-je exporter mes environnements ?

Oui : seules les valeurs partagées sont exportées, jamais les secrets.
